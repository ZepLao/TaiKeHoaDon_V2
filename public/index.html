Xuất chi tiết hóa đơn điện tử ra Excel

1. Tải hóa đơn từ cổng thuế

  1. Đăng nhập hoadondientu.gdt.gov.vn → Tra cứu → Tra cứu hóa đơn.
  2. Chọn tab Tra cứu hóa đơn điện tử mua vào (hoặc bán ra), chọn khoảng ngày → Tìm kiếm.
  3. Ở từng hóa đơn bấm nút Tải về (biểu tượng tải xuống) để lấy file .zip có chứa XML.
  4. Bỏ tất cả file .zip / .xml vào thư mục input (có thể để lẫn bán ra và mua vào, chia thư mục con tùy ý).

2. Xuất Excel
